# BookVerse

Leitor de livros para a web: clássicos de domínio público, seus EPUBs e PDFs,
um leitor confortável no nível de um e-reader e a Lumi, uma IA que ajuda nas
margens.

- **Ler sem barreiras:** clássicos abrem direto, inclusive sem cadastro.
- **Leitor:** páginas ou rolagem, 5 temas de página, 4 fontes (incluindo
  Atkinson Hyperlegible), luz âmbar, brilho, sons ambiente, busca no livro,
  destaques, notas, marcadores e atalhos de teclado.
- **Sete ambientes** para o app inteiro, incluindo Alto contraste.
- **Hábito:** ritual diário de leitura, metas, desafios e ranking.

## Comandos

```bash
npm install
npm run dev      # desenvolvimento em http://localhost:8080
npm run build    # produção (.output/)
npm run lint
npx tsc --noEmit
```
